# Vehicle and licence-plate processing prototype

Python computer-vision experiments for detecting vehicles and handling licence plates across images and selected video workflows.

**Status: prototype.** The November 2026 source-repair pass resolved merge conflicts in `vehicle_detection/main.py`; the GitHub Actions job checks Python compilation and rejects new conflict markers. Detection/OCR accuracy and end-to-end execution remain unverified.

## Project structure

| Directory | Role |
| --- | --- |
| `vehicle_detection/main.py` | Vehicle detection CLI |
| `vehicle_detection/detector.py` | YOLO-based vehicle detection |
| `vehicle_detection/plate_recognizer.py` | Licence-plate processing utilities |
| `vehicle_detection/video_processor.py` | Video processing |
| `vehicle_detection/gui/` | GUI source where available |
| `utils/` | Common vehicle and plate helpers |
| `docs/` | Historical installation and usage notes; verify the entry point against code |

## Getting started

```bash
git clone https://github.com/BalajiKoushik01/licence-plate-detection-and-masking.git
cd licence-plate-detection-and-masking
python -m venv .venv
# Windows: .venv\Scripts\activate
# Unix: source .venv/bin/activate
python -m compileall -q vehicle_detection utils
```

This source tree does **not** contain a single pinned, complete dependency lockfile. The CLI requires packages such as OpenCV and Ultralytics for some workflows. Install only the packages required by your chosen processing path and inspect the code before running `python -m vehicle_detection.main --help`. This check has not been verified in a clean environment.
